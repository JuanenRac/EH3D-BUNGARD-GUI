**正直さの確認 - 現在実際に動くもの：** ウィンドウを持つ Rust プログラムで、コンピューター上で動く 198 件のテストがあります。ランチャーは、手動 (MTC) または自動 (ATC) ツールチェンジのマシン向けに、新しいインターフェースか従来のドリル・ルーティングのプログラムを選べます。ビューアーは、ドリルファイル、HP-GL プロットファイル、作業を収めた ZIP アーカイブをフォルダーブラウザー、ドラッグ＆ドロップ、コマンドラインから開き、ドリル径ごとの穴とその上のルーティング経路を平面図に描き、設定で選んだサイズのテーブルを持つマシンを 3D で表示し、基板を面付けし、実行中の作業を追います。作業は EH3D-DRILLPRO と EH3D-ROUTEPRO のエンジンの**シミュレーター**で動きます。実機への接続方法（コンピューターの RS-232、USB-RS232 アダプター、または EH3D-NODE-BUNGARD を直接あるいは EH3D-SERVER 経由）は、それらが読む同じマシンファイルで決まりますが、**このウィンドウからはどれも試していません**。接続、設定、ツールの各ウィンドウは提供する値だけを変更し、マシンファイルとツールファイル全体はまだ編集できず、3D 表示は経路の高さを示しません。

---

> **安全性とセキュリティの現状：** このプログラムは安全システムではありません。リミットスイッチや非常停止は扱わず、実機を動かしたことは一度もありません。マシンファイルに実際の接続を指定すると、作業は EH3D-DRILLPRO と EH3D-ROUTEPRO のエンジンを通じてマシンを動かします。先にそれらの注意書きを読み、ツールを外し、マシンの電源スイッチに手を置き、いつでも作業を止められるようにしてください。このプロジェクトは独立したもので、Bungard Elektronik が作成・推奨・サポートするものではなく、製品名はどのファイル形式とマシンで動かすことを想定しているかを示すためだけに使っています。

## 🎯 概要

* **ランチャー**：新しいインターフェース、または手動か自動のツールチェンジのマシン向けの従来のドリル・ルーティングのプログラム。従来のプログラムはこのプログラムの隣にあるとき、そのまま起動されます。選択は記憶できます。
* **平面図**：ドリル径ごとの穴とその上のルーティング経路を載せたテーブル。マウスでドラッグし、ホイールでズームします。ボタン（またはダブルクリック）で元に戻ります。
* **マシンの 3D 表示**：レール、穴あきテーブル、可動ガントリー、ツールラック。テーブルは設定で決めたサイズです。ドラッグで回転し、ホイールでズームし、Shift または右ボタンで移動します。マシンのプロファイル（CCD/2、CCD、CCD Premium、CCD XL）は公表されている寸法に基づき、マシンは設定のテーブルから判定されます。
* **ファイルを開く**：ドリルファイル、HP-GL ファイル、作業を収めた ZIP アーカイブを、フォルダーブラウザーとドライブを備えた「開く」ウィンドウ、ウィンドウへのドロップ、`Ctrl+O`、コマンドラインから開きます。作業フォルダーの外に出てしまうアーカイブ内の名前は一覧に出さず、サイズ上限を超えるファイルは読みません。
* **面付け**：基板のコピーを列と行に並べます。基板間の隙間、隣との距離、またはテーブルに収まる最大数で配置し、コピーは描画され、作業でも加工されます。
* **作業**：従来のプログラムのエンジンとそのマシンファイル（`demo` シミュレーター、`rs232`、`usb`、`node`、`server`）で実行し、進行を表示し、マシンからの質問（スピンドル、ツールチェンジ）をオペレーターに尋ねます。
* **基板と工具**：多くのメーカー（Bungard、Fortex、CIF、汎用 FR-4、CEM と FR-2、Isola、Panasonic、Shengyi、ITEQ、Ventec、Nelco、Arlon、Rogers、Taconic、Bergquist、DuPont、MG Chemicals、MSC、Yuxinda、ThinFlex）の基材ライブラリから、材質、厚さ、銅、銅の面数、サイズを選び、記憶します。作業の工具は穴あけまたはルーター加工として送りと回転数つきで一覧され、作業中のものが点灯します。各値には既定値（ドリルの直径と基板の材質から決まります）があり、クリックして入力することもできます。
* **フライス加工と穴あけ用の銅なし板材：** 銅張り基板のほかに、一般的な厚さの素板（アルミ合金 0.2〜5 mm、銅 0.1〜5 mm、PTFE 0.2〜5 mm、バーチ合板、MDF、バルサ材、シナノキ材 0.5〜5 mm、アクリル、ポリカーボネート、ABS、POM、ナイロン、PVC、HDPE、PETG、G10、フェノール紙）をライブラリに収録しています。銅はなく（基板ウィンドウにその旨が表示され、銅の面の選択は隠れます）、誰も公表していない電気特性も載せません。材料の種類ごとに穴あけとルーティングの開始回転数・送り・1回の切込み深さがあり、常にスピンドルの限界内です。
* **設定**：テーマ、言語、テーブルの使用可能サイズ、シミュレーションの速度（作業は実機と同じ時間で進み、x0.5 から x50 まで）、工具交換と主軸始動のときに確認するか、次回からこの画面を直接開くか。ボタンはポインターの下で光り、押すと沈みます。
* **パネル外形の切り残し：** パネル化ウィンドウで外形を切り残し付きでルーティングでき、割り取るまで基板を保持します。1辺の数、幅、位置（均等、両端寄り、中央にまとめる）を選べ、平面ビューには切断されたパスが表示されます。基板のメーカー、厚さ、サイズもドロップダウンで選びます。
* **テーブル校正：** 設定ウィンドウのタブが点のグリッド（既定は 7 x 5）でテーブルの高さを測定し、マップ（青が低く赤が高い）、高低差、1 メートルあたりの傾き（mm）を表示して、マシンとともに保存します。プローブノードが接続されるまでプローブはシミュレートで、ジョブへの補正はまだ適用されません。
* **クラッシュ後もジョブを続行：** ジョブの実行中、続行に必要な内容（ファイル、パネル、開け終えた穴）をリアルタイムで保存します。ウィンドウ、PC、接続が落ちた場合、次回起動時に続きから再開するか破棄するかを確認します。ウィンドウは最大化で開き、ジョブのボタンは明るい色（開始は緑、一時停止は青、停止は赤）です。
* **音声通知：** 音のほかに、ジョブ終了と工具要求を音声で知らせることができ、言語と性別は同じ音のリストから選びます（`sound_finish = voice:es:f`）。`voices/` フォルダーの音声は合成（Piper）で自由に配布でき、ゆっくりした丁寧な文です。27 言語に音声があります（最初の 7 言語に加えて、ブルガリア語、チェコ語、デンマーク語、オランダ語、エストニア語、フィンランド語、ギリシャ語、ハンガリー語、ラトビア語、ノルウェー語、ポーランド語、ルーマニア語、スロバキア語、スロベニア語、スウェーデン語、ウクライナ語、ロシア語、アルバニア語、バスク語、ブラジルのポルトガル語。新しい音声の性別は聞いて確認していないので、確かめてください）。その他（日本語、クロアチア語、アイルランド語、マルタ語、カタルーニャ語、ガリシア語、セルビア語、アイスランド語、リトアニア語）には自由に配布できる音声がなく、音で知らせます。中国語とポルトガル語の女性の音声、人による実際の録音はありません。同じフォルダーに自分の WAV ファイルを置くと置き換わります。`voices/README.txt` を参照してください。
* **工具カタログ：** ウィンドウ（工具ウィンドウから開く）に、Bungard のチャックが保持する 1/8 インチ（3.175 mm）シャンクの工具を450本以上、12種類で一覧表示します。0.05 mm のマイクロシリーズから 7 mm までのドリル（小径・中径・チップブレーカー付き大径）、長穴用ドリル、ダイヤモンドカット、ダウンカット、アップカット、チップブレーカー、ダイヤモンドコーティングのルーター、エンドミル、Vビット、ボールエンドミル、センタードリル、面取りカッターです。それぞれにシリーズ、刃長、メーカーの FR-4 表の回転数・送り・1回の切込み深さがあり、クリックすると工具を（寸法付きで）描き、用途を説明します。表より回転数の低い主軸（既定は 24 000、ウィンドウで変更可）には、送りを比例して下げた同じ工具が適用されます。Vビットは、ある深さでの溝の幅を示します。 サンプル基板には V ビットで切る 4 本の配線のアイソレーションがあります（ルーティング表の工具 3）。
* **ジョブはテーブルに追従し、ドリルヘッドのノード：** 校正タブのチェックボックスで、穴あけとルーティングがテーブルの高さマップで Z を補正します（完全なマップのみ、求めたときのみ）。ウィンドウ（接続ウィンドウから開く）で EH3D-NODE-BUNGARD-AUX への接続方法（使わない、直接、サーバー経由）、そのアドレスとトークン、カメラ表示の有無を設定し、カメラの映像、スピンドルの回転数と温度、保護出力、ヘッド下のテーブルの測定を表示します。サーバー経由では、接続ウィンドウのアドレス・トークン・マシン ID を使ってサーバー越しにノードへ問い合わせます（ノードのトークンはサーバーが保持）。校正のプローブはまだシミュレートです。
* **見やすく動かしやすく：** ジョブカードのツール一覧はスクロールし、レイヤーがウィンドウの外へ押し出されません。開いたドロップダウンリストはすべてスクロールバーが機能します（ドラッグ、クリック、ホイール）。2D ビューのボタンで基板とテーブルはそのままにデザインだけを動かせます。各ルーターツールは 2D と 3D ビューで独自の色になり（ミルが3本のファイルでは3色）、タブはコピーが1つだけでも基板の外周に切り込まれ、内側のポケットやトラックには入りません。
* **控えめなアニメーション：** 画面とウィンドウはフェードインで開き、ジョブの実行中はヘッドのリングが呼吸して波紋を出し、これから切る経路の破線がそれに沿って流れ、進捗バーを光が横切り、作業中のツールが一覧の中で呼吸します。停止中は何も動きません。

## 🧩 EH3D での役割

EH3D-BUNGARD-GUI は、EH3D ファミリーにおける Bungard マシン用の新しいインターフェースです。隣のフォルダー EH3D-COMMON（`eh3d-view` のシーン、テーマ、37 言語のテキストと `eh3d-archive` の ZIP リーダー）、EH3D-DRILLPRO、EH3D-ROUTEPRO（それらのエンジンと従来のプログラム）にパスで依存するため、これらをこのフォルダーの隣に置く必要があります。

* マシンとステーションのウィンドウ：サーバー接続時、サーバーのすべてのマシンをステーション別に、各マシンの状態、進捗付きのジョブ、準備済みジョブとともに表示し、このウィンドウのジョブの送り先マシンを選びます。`--fleet FILE.json` はサーバーなしで保存済みの応答を表示します。
* 設定でマシンモデルを選ぶと、2 つの表示がそのテーブルに合います。2D 平面図、3D マシン（そのモデルのフレーム、レール、ガントリー、工具ラック）、ズームが新しい寸法でやり直されます。
* ZIP アーカイブ内の作業：最初のドリルファイルと最初のルーティングファイルを表示し、残りは一覧からクリックで読み込めます。
* 3 つのモード（隙間、ピッチ、収まる最大数）での面付けと、テーブル上へのコピーの描画。
* 作業の進行のライブ表示と、マシンからオペレーターへの質問。
* バージョン、ライセンス、使用中の接続を示すバージョン情報ウィンドウ。
* タブ付きの設定で、すべての Bungard MTC と ATC モデル（テーブル、ツールチェンジャー、リミット）と、ステップと座標の単位（mm または mil）を扱い、すべてがジョブに実際に反映されます。
* 表示・非表示・ドラッグができる非常停止ボタン。ジョブの実行中は Start が消え、一時停止または停止で戻ります。シミュレーションはバックグラウンドでも続きます。
* 各ツールに追従する 2D ビュー、穴あけファイルとルーティングファイルの同時回転、基板の移動、100 種類を超えるベース材料のライブラリ、ジョブ終了時とツール交換時のサウンド。
* 他のプログラムのファイル：Gerber 基板の外形（`.GKO`、`.GM1`、`.GML`、またはプロファイルと名乗る `.GBR`）と DXF 図面をルーティングジョブとして開きます。プロッターファイルの円と円弧（`CI`、`AA`、`AR`）は、設定の弦角で弦に分割されます。
* テーブルに収まらないジョブは開始前に拒否されます。「開く」ウィンドウは最近開いたファイルを一覧にし、ツールウィンドウは基板上と全ジョブでの各ドリルの穴数を数え、カウントをやり直すボタンがあります。
* ファイルを開くと（「開く」ウィンドウ、最近のファイル、ドロップのいずれでも）、従来のプログラムが読み込み後に工具を表示するのと同様に、工具ウィンドウがファイルの上に開きます。設定のチェックボックスでオフにできます。

* **ヘッドのカメラによる照明と品質チェック：** ノード画面で LED リングをオン・オフし、「品質チェック」画面では加工後の基板を確認します。ジョブの穴（有無・真円度・サイズ・位置）、フライス溝（工具どおりの幅・均一・くびれなし）、画像そのものを判定し、各穴を画像上に表示し、看板のように大きな判定（合格・不合格・判定不可）を示して、LED リングも同じ結果を色で示します。プロファイル（標準・ファインピッチ・試作）、公差、スケールと既知の穴での校正はファイルに保存され、サーバーにも渡されます。結果は音声で知らせることもできます。設定に、チェックが合格のときと不合格のときの 2 つの音が加わり、それぞれオフ、ビープ音、カタログの音、自分のファイル、または「基板の目視チェックは合格／不合格です」と話す音声を選べます（他の音と同じです）。
* **実機と同じように動く 3D マシン：** 停止中のヘッドはホームで待機し、平面ビューで基板を動かしてもマシンは動きません。ジョブを始めるとマシンが起動してホームに戻り、作業の最初の点まで移動し、そこで初めて作業が始まってヘッドがそれに従います（穴あけも切削も同じです）。終わるとホームに戻ります。リストのバーには上下の矢印があります。
* **2 つの主軸とそれを知るカタログ：** マシンは純正主軸（63000 rpm）またはインバーター付き主軸（24000 rpm）を搭載し、設定で選びます。それぞれの限界（回転数・XY と Z の送り・最も太い工具）は設定ファイルに保存されます。工具の画面では各工具に「カタログ」ボタンがあり、ドリルやフライスを選ぶとその回転数・送り・切込みが工具に反映されます。主軸が出せない場合は画面がそれを示し、使える値（1 回転あたりの切込みを保つ、XY や Z を遅くする）を提案するか、非対応として採用できなくします。基板の一覧は 16 材料を一度に表示します。
* **穴あけ・切削・両方を工具ごとに選択：** 左パネルと工具の画面で、作業の穴あけと切削をオン/オフできます（両方オンなら穴あけ→切削の順に続けて実行し、間でマシンはホームに戻りません）。各工具の点をクリックするとその工具を外して作業から省きます。
* **複数ファイルの同時読込とプロ仕様のサンプル：** 「開く」画面で Ctrl+クリックまたは Shift+クリックにより 2 つ以上のファイルを選べます（穴あけと切削を一緒に。同じ種類が複数ある場合は 1 つの作業にまとめ、工具は径で番号付け）。パッケージの `examples` フォルダーには、穴あけと切削のファイルを備えた実際の複雑さの設計が 4 つあります。32 ビットマイコン基板（ピンヘッダー、USB 切欠き、LQFP のビアリング）、4 チャンネルのアナログフロントエンド（DIP アンプ、BNC と端子台、ガードリング、絶縁スロット）、2.4 GHz アンプとフィルター（エッジ SMA、ビアフェンス、シールドの縫い付け、50 オーム線に沿った絶縁ミリング）、5 V 3 A 電源（TO-220、電解コンデンサ、サーマルビア）です。
* **37 言語：** ウィンドウ全体が対応する言語：英語、スペイン語、イタリア語、ドイツ語、フランス語、ポルトガル語、中国語、日本語、ブルガリア語、クロアチア語、チェコ語、デンマーク語、オランダ語、エストニア語、フィンランド語、ギリシャ語、ハンガリー語、アイルランド語、ラトビア語、リトアニア語、マルタ語、ポーランド語、ルーマニア語、スロバキア語、スロベニア語、スウェーデン語、ノルウェー語、アイスランド語、ウクライナ語、ロシア語、セルビア語、アルバニア語、カタルーニャ語、ガリシア語、バスク語、ブラジルのポルトガル語、カナダのフランス語。 最初の 8 言語以外の 29 言語はモデルによる翻訳で、ネイティブによる確認待ちです。ない文言は英語で表示されます。 機械のノードの Web パネルも 37 言語すべてに対応します。機械の画面（HMI）は当面、最初の 8 言語のままです。
* **Windows で黒い画面が出ない：** ウィンドウ付きのプログラム（本プログラム、DRILLPRO、ROUTEPRO、MOTIONCNC）は Windows でコンソールを開きません。ターミナルから起動した場合は、ヘルプとエラーをそこに出力します。**動かせるウィンドウ：** メインの上に出るウィンドウはすべて上部をドラッグして動かせ、右上に X ボタンがあります。
* **「開く」ウィンドウのプレビュー：** 開く前に、選んだ穴あけ／ルーティングファイルの平面図をリストの右側に描きます（直径付きの穴、経路、基板のサイズ）。下のスイッチで有効／無効を切り替えると、リストは平面図が空けた分の幅を使います。選択は保存されます。
* **平面ビューでのジョブ編集：** 左のリストの工具をジョブから外せます（その穴や経路はファイルとすべてのビューから消えます）。平面ビューでは選択ツールで、クリックまたは枠で穴と経路を選べます（左から右：完全に枠内のもの、右から左：枠に触れるもの、Ctrl または Shift で追加）。ボタン、または Ctrl+C、Ctrl+X、Ctrl+V、Ctrl+A、Delete で、コピー、数ミリずらして貼り付け、切り取り、削除ができます。編集で書き出されるのは新しいファイルで、元のファイルは変更されません。
* **立体感とアイコンを全面に：** ボタン、チェックボックス、テキストボックス、リストのバー（小さな矢印ボタン付き）、リストの枠にグラデーション、光る縁、影を付け、すべてのテーマでポインタに反応して光り、押すと沈みます。ウィンドウ隅の X は赤く、ポインタを乗せると回転して光ります。平面ビューと「開く」ウィンドウの小さなボタンは、名前を示すヒント付きのアイコンになりました。
* **平面ビューの編集の拡充、工具からの開始、シリアルポート：** 選んだものはドラッグ（または矢印キーで移動：1 mm、Shift で 0.1 mm、Ctrl で 10 mm）や切り取りができ、すべての編集を元に戻す／やり直せます。面付けでは、どのコピーの穴も基板の同じ穴です。リストの各工具に、その工具からジョブを始めるボタン（それ以前の工具は除外）があり、完了した穴や経路の数と全体の数を表示します。面付け後は、両方のビューが作業の中心に戻ります。接続ウィンドウは RS-232 と USB-RS232 のためにシステムのシリアルポートを一覧し、最初のものを自動で選びます。
* **ランチャー、パネル、レイヤーに立体感：** ランチャーのカードとパネルにグラデーション、影、ポインタ下の光を付けました。ジョブの工具リストとレイヤーのチェックボックスもポインタに反応し、ランチャーへ戻る「<」はヒント付きのボタンになりました。
* **ATC モデルの自動工具交換：** ジョブを始める前に、ラックのスロット（スロット0はスピンドルにあるテスト工具で空けておく）と、ジョブが使う順にどの工具をどのスロットに入れるかをウィンドウに表示します。ラックに入りきらない数の工具を使うジョブは、入る分、ラックを入れ替える停止、残り、という順に分けて行います。穴あけとルーティングの工具は、入る限り同じ装填を共有します。
* **ATC モデルの工具バー：** 工具が待機する機械端のバーを、平面ビューと 3D ビューに描きます。番号付きで並ぶ位置、そこにある工具（サイズの色と番号）、ヘッドにある工具、次に取る工具、使用済みの工具を戻す空き位置です。設定ウィンドウのボタンから、最初と最後の工具の正確な位置（X、Y、Z）と位置の数を設定するウィンドウを開きます。間の位置は等間隔で配置され、交換装置の他の位置とともに機械ファイルに保存されます。工具の長さ（38 mm、リングから先端まで 21 mm）、チャックが工具の上を移動する高さ、進入する側も同じファイルに保存されます。**これらは実機では一切試していません。**
* **基板ライブラリの Bungard カタログ：** Bungard の4種類の材料に 2024/25 年カタログのデータ（厚さ 0.5〜2.5 mm、銅箔 18・35・70 um と 1.5 mm での 105 um、標準カット寸法、510 x 570 および 510 x 1150 mm のパネル、FR2・FR3・CEM-1 のパネル）を入れました。スピンドルのカタログ、品質チェック、材料の矢印と数値ボックスにもアイコンと立体感を付けました。

## 🔌 インターフェース

* **ウィンドウ：**ランチャーとビューアー。マウスとキーボードで操作します（`Enter` でランチャーの選択を決定、`Esc` で戻る、`Ctrl+O` でファイルを開く）。
* **コマンドライン：**`bungard-gui [ファイル...] [--drill FILE.NCD] [--route FILE.PLT] [--zip JOB.ZIP] [--lang CODE] [--theme NAME] [--data DIR] [--connection FILE] [--screen launcher|viewer]`。オプションなしのファイルは拡張子に従って開かれます。`--modal`、`--panel`、`--yaw`、`--shot`、`--start` は、画像用にウィンドウ、パネル、3D 表示の回転、ウィンドウの画像、作業の開始を指定します。
* **マシン：**EH3D-DRILLPRO と EH3D-ROUTEPRO のエンジンと、それらが共有するマシンファイルを通じて、コンピューターの RS-232、USB-RS232 アダプター、EH3D-NODE-BUNGARD、または EH3D-SERVER で接続します。マシンファイルがなければ作業はシミュレーターで動きます。

## ⚙️ 設定

接続は EH3D-DRILLPRO と EH3D-ROUTEPRO の**マシンファイル**（`machine.cfg`。`connection = demo|rs232|usb|node|server` と、実機で調整した各値）で決まります。`--connection FILE` でそれを指定し、なければ作業はシミュレーターで動きます。`--data DIR` は従来のプログラムのマシンファイルとツールファイル（`DRILLPRO.DCF`、`DRILLPRO.DTD`、`ROUTEPRO.RCF`、`ROUTEPRO.RTD`。`testdata/` にサンプルがあります）のフォルダーです。設定ウィンドウはテーブルの使用可能な幅と奥行きを変更し、それらのファイルに保存します。ウィンドウが記憶するもの（ランチャーの選択、言語、テーマ）は、他の EH3D プログラムと同じユーザーの設定フォルダー内の小さなファイルに保存されます。`--theme forge|neon|glass|windows-classic|system` と `--lang en|es|it|de|fr|pt|zh|ja` で外観と言語を選びます。

## 🗺️ ロードマップと既知の制限

**現時点で分かっている制限**

* このウィンドウから実機で作業を動かしたことはありません。EH3D-DRILLPRO と EH3D-ROUTEPRO のエンジンのシミュレーターでのみ動かしました。
* 接続ウィンドウがマシンファイルに書くのは接続のキーだけです。設定ウィンドウは提供するキー（テーブル、モデル、単位、サウンド、シミュレーション速度）を、ツールウィンドウは送り、回転数、深さを書き込みます。マシンファイルとツールファイルのそれ以外はここでは編集できません。
* 一時停止は 2 つの動きの間で作業を止め、動きの途中では止めません。3D 表示は経路の高さを示しません。
* 制御できるのは CCD と CCD/2 のみです。CCD Premium と CCD XL のプロファイルは描画しますが、それらの制御ユニットには対応していません。
* パスで依存しているため、ウィンドウの隣に EH3D-COMMON、EH3D-DRILLPRO、EH3D-ROUTEPRO のフォルダーが必要です。

**次のステップ**

* 2 つの動きの間だけでなく、動きの途中での一時停止。
* 3D 表示での経路の高さ (Z)。
* テーブルサイズだけでなく、設定全体の読み込みと保存。
* 従来のプログラムを同梱し、1 回のダウンロードですべてがそろうパッケージ。
* 実機でのテスト。
