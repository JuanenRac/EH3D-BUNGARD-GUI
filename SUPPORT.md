# Support

* **Questions and ideas:** open an issue with the form that fits.
* **A file that does not open or looks wrong:** attach it (or the smallest one that shows the problem), the machine or table size you use and the message the window gave. A picture of the window helps.
* **Machine connection questions:** the machine file is the one of EH3D-DRILLPRO and EH3D-ROUTEPRO; read their connection notes first.

This is a one-person project and the program is at its first steps: answers can take a few days.
